# Behavior Detection Web (React + Tailwind CSS)

    npm install
    npm run dev

- `/`          Trang quản trị: Sidebar + 4 tab (Analyze Video, Batch Processing, Dashboard, History)
- `/analysis`  Trang giám sát CCTV, tự làm mới mỗi 3 giây

Dữ liệu hiện là dữ liệu mẫu. Các chỗ cần nối backend (FastAPI) được đánh dấu `TODO` / "thay bằng ... /api/..." trong code.
Màu cảnh báo khai báo trong `src/index.css` (`bg-fighting`, `text-falling`, `border-loitering`, `bg-safe`).
